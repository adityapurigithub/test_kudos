# Kudo App  

A modern MERN stack application for sending and receiving kudos, featuring an intuitive UI built with Material-UI, private routing for secure interactions, and an analytics dashboard for insights.  

## Features  
- Send kudos to users with personalized messages.  
- Interactive dashboard for liking/unliking kudos.  
- Analytics dashboard to track trends and team engagement.  
- Secure authentication and private routing.  
- Beautiful, responsive UI built with Material-UI components.  

## Prerequisites  
- **Node.js** (v16 or later)  
- **MongoDB** (local or cloud instance)  
- **npm** (Node Package Manager)

## Getting Started  

### 1. Clone the Repository  
```bash
git clone https://github.com/your-username/kudo-app.git
cd kudo-app
```

Scripts:
Backend-
  npm run server — Starts the backend server.
Frontend-
  npm run dev — Starts the development server for the frontend.
