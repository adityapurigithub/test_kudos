# Kudo App

A modern MERN stack application for sending and receiving kudos, featuring an intuitive UI built with Material-UI, private routing for secure interactions, and an analytics dashboard for insights.

## Features

- **Send & Like Kudos**: Users can send & like personalized kudos with messages.
- **Interactive Dashboard**: Users can like/unlike kudos and track real-time updates.
- **Analytics Dashboard**: Visual insights to track engagement and trends.
- **Secure Authentication**: Ensures safe and private interactions with private routing.
- **Responsive Design**: Built with Material-UI components for a seamless experience across devices.

---

## Prerequisites

- **Node.js** (v16 or later)
- **MongoDB** (local or cloud instance)
- **npm** (Node Package Manager)

## Getting Started

### 1. Clone the Repository

```bash

git clone https://github.com/your-username/kudo-app.git
cd kudo-app

cd server
npm install

cd ../client
npm install

# Start the backend server: **IMP : please remove the .txt extension from server.js file**
cd server
npm run server

# For creating a deployment build
npm run build



# Start the frontend development server:
cd ../client
npm run dev

# For creating a deployment build
npm run build

```
